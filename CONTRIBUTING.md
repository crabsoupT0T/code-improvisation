# Contributing to Code Improvisation

This project only works if people show up and play.

## Fast path

1. Fork the repo.
2. Create a branch: `git checkout -b improv/your-idea`
3. Add something under `stage/` or improve something in `remixes/`.
4. Open a pull request. Describe what you riffed on and why.

## What we want

- Unfinished ideas (that is the point)
- Remixes of other contributors' snippets
- Small web pages in `site/` that help people assemble
- Issue templates, bots, docs — anything that lowers the cost of contributing
- Discussions-style threads started as GitHub Issues if Discussions is not on yet

## What we do not want

- Drive-by spam
- Secrets, credentials, or scraped personal data
- Content that is illegal or abusive

## Issue labels we try to use

- `prompt` — an idea waiting for a first implementation
- `remix-this` — someone wants the community to take their snippet further
- `good-first-improv` — small enough for a first PR
- `web` — work on the public site

Thank you for assembling here.
